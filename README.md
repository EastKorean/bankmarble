# 🐷 뱅크마블

초등 금융교육용 실시간 멀티플레이 보드게임입니다. 학생들이 각자 기기로 접속해 주사위를 굴리고, 가계부를 직접 쓰고, 저축카드로 예금해 이자를 받습니다.

**추가 설치가 필요 없습니다.** Node.js만 있으면 바로 실행됩니다.

## 1. 교실에서 바로 쓰기 (선생님 컴퓨터를 서버로)

1. https://nodejs.org 에서 Node.js(LTS)를 설치합니다.
2. 이 폴더(`bankmarble`)를 압축 해제합니다.
3. 폴더 안에서 터미널(Windows는 "명령 프롬프트")을 열고 실행합니다.
   ```
   node server.js
   ```
4. 화면에 나온 주소를 확인합니다.
   - 선생님: `http://localhost:3000`
   - 학생: `http://192.168.x.x:3000` (같은 와이파이에 연결된 기기)
5. 선생님이 **방 만들기** → 화면에 나온 방 번호를 학생에게 알려 줍니다.
6. 학생이 주소에 들어가 방 번호와 닉네임을 넣고 말을 고릅니다.
7. 선생님이 **게임 시작**을 누릅니다.

> 학생 기기가 접속되지 않으면 Windows 방화벽에서 Node.js의 "개인 네트워크" 접근을 허용해 주세요. 학교 와이파이가 기기끼리의 연결을 막는 경우도 있어요. 그럴 땐 아래 2번 방법을 쓰세요.

## 2. 인터넷에 올려서 쓰기 (어디서나 접속)

Node.js를 지원하는 무료 호스팅(Render, Railway 등)에 이 폴더를 올리면 됩니다.

- 시작 명령: `node server.js` (또는 `npm start`)
- 포트: 호스팅이 주는 `PORT` 환경변수를 자동으로 씁니다.
- 무료 요금제는 한동안 접속이 없으면 서버가 잠들 수 있어요. 수업 전에 한 번 열어 깨워 두세요.

## 게임 규칙 요약

- 24칸 보드를 시계 방향으로 돕니다. 시작 칸을 지나면 +2,000원, 다음 라운드.
- 수입/지출 칸: 돈은 자동으로 바뀌고, **가계부에 금액과 잔액을 직접 적어야** 다음 주사위를 굴릴 수 있어요. 틀리면 "실제보다 모자라요/많아요"로 알려 줘요.
- 저축카드 칸: 카드 1장을 받아 모아 둡니다. **2라운드부터**, 자기 차례에 주사위를 굴리기 전에 **은행 예금하기**로 사용해요(1만원 단위).
- 예금 후 처음 시작 칸을 지나면 원금 + 이자를 자동으로 돌려받아요. 이자 = 예금(만원) × 카드의 1만원당 이자.
- 예금은 한 번에 1건. 만기가 된 카드는 가운데 카드 더미로 갑니다.
- 무인도: 다음 차례 한 번 쉬기. 돈이 모자라면 빚(마이너스)도 가능해요.
- 설정한 라운드를 마치면 완주. 모두 완주하면 게임 끝, 최종 자산(현금 + 예금 원금) 순위.

## 선생님(진행자) 기능

- 방 만들기: 라운드 수 5~10, 시작 자금, 최대 10명
- 대기실: 설정 변경, 학생 내보내기
- 게임 중: 교실 화면용 큰 보드, 학생 이름을 누르면 그 학생의 가계부 보기, 차례 넘기기(접속이 끊긴 학생 등), 지금 게임 종료, 전체 화면
- 게임 후: 최대 10라운드까지 **게임 연장**, 강제 종료했다면 **게임 이어하기**

## 재접속

새로고침하거나 인터넷이 잠깐 끊겨도 자동으로 다시 연결됩니다. 다른 기기에서는 **같은 방 번호와 닉네임**으로 들어오면 이어서 할 수 있어요. 서버를 껐다 켜도 `data/rooms.json`에 저장된 게임이 복구됩니다. (24시간 동안 쓰지 않은 방은 자동 삭제)

## 파일 구성

```
server.js        게임 규칙과 실시간 서버 (Node.js 기본 기능만 사용)
public/index.html
public/style.css 화면 디자인
public/app.js    학생/선생님 화면
public/sound.js  배경음악과 효과음 (소리 파일 없이 브라우저에서 직접 만듦)
```

게임판 칸의 내용과 금액, 저축카드 구성은 `server.js` 위쪽의 `BOARD`, `CARD_SET`에서 바꿀 수 있어요.
